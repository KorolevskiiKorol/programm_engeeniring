# Демонстрация интеграции Redmine + Git

Этот файл создан для демонстрации автоматической привязки коммита к задаче Redmine.

## Механизм работы
- В сообщении коммита используется ключевое слово `refs #<номер_задачи>`
- Redmine автоматически создаёт связь между коммитом и задачей
- В карточке задачи в разделе "Связанные изменения" отображается коммит
