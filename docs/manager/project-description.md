# АИС интернет-магазина цветов

Учебный проект по дисциплине «Основы программной инженерии» (ГУАП).
Вариант задания: №42.

## Цель проекта
Автоматизация продажи цветочной продукции, управления каталогом,
остатками, заказами, оплатой, сборкой букетов и доставкой.

## Функциональные требования
FR-01 — FR-52 (из ЛР №1)

## Бизнес-правила
RULE-01 — RULE-20 (резервирование, замены, интервалы доставки)

## Границы проекта
Входит: каталог, корзина, оформление, оплата, доставка,
личный кабинет, управление заказами, ассортимент, коммуникации.

Не входит: банковский процессинг, закупки, бухгалтерский учёт,
оптимизация маршрутов курьеров.
