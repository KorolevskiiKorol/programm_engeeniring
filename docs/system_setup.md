Лабораторная работа № 2, проект «Интернет-магазин цветов».
Роль — специалист по информационным системам.

Для работы с задачами проекта Redmine 7.0.3 развёрнут в Ubuntu 26.04.1 
LTS на виртуальной машине VirtualBox. 
Apache с модулем Passenger обслуживает веб-приложение, 
данные хранятся в PostgreSQL. 
Стенд проверен по адресу http://127.0.0.1/ в браузере внутри виртуальной машины.
Что выполнено
- Создан снимок состояния виртуальной машины перед установкой.
- Настроено подключение Redmine к PostgreSQL. 
Выполнены миграции и загружены начальные данные.
- Проверен вход в Redmine, изменён начальный пароль администратора 
и включена тема Opale 1.7.2.
- Созданы дамп PostgreSQL и архив файлов Redmine с конфигурацией Apache. 
Проверено, что списки содержимого обоих файлов читаются.
На странице Administration → Information подтверждены версия Redmine, 
подключение к PostgreSQL, выполнение миграций и активная тема Opale. 
Команды установки и скриншоты приведены в отчёте по лабораторной работе.
